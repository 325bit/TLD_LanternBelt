# Lantern Belt

站在暴风雪里，你想一边打灯一边腾出手来开门、生火、举枪——原版做不到：提灯必须拿在手上，一旦换手就会熄灭。

这个 mod 把点着的煤油提灯挪到腰上：手空出来了，灯照样亮、照样烧油、照样发热。

*A The Long Dark mod that hangs a lit kerosene lantern on your belt, keeping both hands free.*

## 功能

**挂腰**

- 在物品界面选中背包里的提灯，按钮显示「挂到腰上」，点一下挂好，双手恢复为空。
- 挂好后同一个按钮变成「从腰上收起」，再点一次收回背包。
- 挂上去自动点燃：照明范围、烧油速度、取暖效果全部沿用原版数值，腰上那盏灯是真的在烧油、真的在散热。
- 挂腰时不占用手部：可以同时拿步枪、信号棒、爬绳、生火、开门。

**开关灯**

- 挂腰状态下按 `L` 开关提灯。
- 没挂腰（收起或拿在手上）时 `L` 完全不响应，不会抢游戏原有按键。
- 灯里没油时按 `L` 只给一行提示，不会点出一盏空灯。

**存档**

- 读档、进出建筑 / 洞穴后，腰上那盏灯会自动回来，不用手动重挂。

**兼容**

- 风暴灯、矿工灯都支持。识别依据是提灯本身的组件，不看物品名字，后续同类提灯同样适用。
- 丢弃、存进容器、被拿去点火把时，挂腰状态会先自动解除，交回原版逻辑。

## 前置条件

- 《The Long Dark》**2.55**（本 mod 针对 2.55 编译）
- [MelonLoader](https://melonwiki.xyz/) **0.7.3** 或更高（实测环境 0.7.3）
- **ModSettings**（必需，设置页依赖它）

## 安装

1. 确认游戏目录下已有 `MelonLoader/` 文件夹（没有就先装 MelonLoader 并启动一次游戏）
2. 把 `LanternBelt.dll` 复制到 `TheLongDark/Mods/`
3. 重启游戏

## 使用

1. 打开背包，点击背包里的一盏提灯
2. 在右侧物品面板点「挂到腰上」——提灯挂到腰上并亮起
3. 按 `L` 开关；再点一次面板上的「从腰上收起」即收回背包

设置入口：**选项 → Mod Settings → Lantern Belt**。

## 设置

| 项 | 说明 | 默认 |
|---|---|---|
| 开关提灯（仅挂腰时） | 只在提灯挂腰时生效，其余时候按了没有反应 | `L` |
| 挂上去就点亮 | 关掉则挂上时保持熄灭，需要按开关灯键自己点 | 开 |
| 收起时熄灯 | 关掉则收进背包后灯继续烧油 | 开 |
| 读档后自动恢复 | 读档 / 换场景后自动把点着的提灯重新挂回腰上 | 开 |
| 显示屏幕提示 | 挂上 / 收起 / 没油时在屏幕中间提示一行 | 开 |
| 保留原版「装备」行为 | 开着则物品栏按钮恢复原版「拿到手上」，挂腰功能整体失效 | 关 |
| 挂点基准 | 「玩家身体」跟着身体走；「相机」跟视角走，晃动更明显 | 玩家身体 |
| 左右偏移（米） | 负值在左胯，正值在右胯 | -0.22 |
| 上下偏移（米） | 相对脚底的高度 | 0.95 |
| 前后偏移（米） | 正值朝前 | 0.12 |
| 整体缩放 | 挂点选「相机」时通常要降到 0.5 左右 | 1.0 |
| 每帧对齐挂点 | 关掉后灯会留在原地，只在排查问题时关 | 开 |
| 提示语言 | 影响屏幕提示与物品栏按钮文字 | 自动 |
| 输出详细日志 | 把挂点、渲染器、层、热量源写进 `MelonLoader/Latest.log` | 关 |

## 调整挂点位置

默认位置是玩家左胯。如果灯飘在半空、穿进身体或看不见，只调三项偏移即可，全部拖动即时生效，不用重开游戏：

- **灯太低 / 太高**：改「上下偏移」，0.95 大约是腰的高度
- **灯在身体里面**：把「前后偏移」加大，或把「左右偏移」往 0 收
- **灯看不见**：先确认不是被衣服挡住，再把「挂点基准」切成「相机」并把缩放压到 0.5 左右

## 卸载

删掉 `TheLongDark/Mods/LanternBelt.dll` 即可。

存档里不会留下本 mod 的字段。已挂腰的提灯在卸载后会变回「背包里一盏点着的灯」，按原版规则它会继续烧油——记得先收起再卸载。

## 兼容性

- 只在提灯挂腰的那段时间里接管提灯的位置、渲染与开关状态，其余时候对游戏没有任何改动。
- 不修改物品定义、燃油消耗速率、光照强度，也不改装备栏以外的任何界面。
- 与其它装备类 mod 无已知冲突（未做系统性组合测试）；真正会互相影响的是也去接管提灯开关的 mod。

## 常见问题

**点了按钮没反应？**  
看设置里「保留原版『装备』行为」是不是被打开了；打开时按钮是原版动作，挂腰功能不生效。

**`L` 按了没反应？**  
`L` 只在挂腰状态生效。先确认物品栏按钮显示的是「从腰上收起」而不是「挂到腰上」；也可能是被别的 mod 占用了同一个键，改绑即可。

**灯挂上了但看不见？**  
先打开设置里的「输出详细日志」，进游戏复现一次，`MelonLoader/Latest.log` 里会有一行「[挂腰] 诊断」，记录渲染器数量、层号与坐标。照着「调整挂点位置」三项偏移微调；日志里渲染器数量为 0 说明这盏灯的模型不随物品加载，请带上这一行反馈。

**腰上没有热度？**  
1.0.0 起挂腰会重新登记热量源。若仍是凉的，打开「输出详细日志」看诊断行里的「热量源」是否显示「已开」。
