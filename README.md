# Lantern Belt

站在暴风雪里，你想一边打灯一边腾出手来开门、生火、举枪——原版做不到：提灯必须拿在手上，一旦换手就会熄灭。

这个 mod 把点着的煤油提灯挪到腰上：手空出来了，灯照样亮、照样烧油、照样发热。

*A The Long Dark mod that hangs a lit kerosene lantern on your belt, keeping both hands free.*

## 功能

**挂腰**

- 在物品界面选中提灯点「装备」，提灯挂到腰上，双手恢复为空。
- 挂上去自动点燃：照明范围、烧油速度、取暖效果全部沿用原版数值。
- 再点一次同一个位置（或按挂起键）就收起，收起的瞬间自动吹灭，油不会白烧。
- 挂腰时不占用手部：可以同时拿步枪、爬绳、生火、开门。

**开关灯**

- 挂腰状态下按 `L` 开关提灯。
- 收起或拿在手上时 `L` 完全不响应，不会抢游戏原有按键。
- 灯里没油时按 `L` 只给一行提示，不会点出一盏空灯。

**存档**

- 读档、进出建筑 / 洞穴后，腰上那盏灯会自动回来，不用手动重挂。

**兼容**

- 风暴灯、矿工灯都支持。识别依据是提灯本身的组件，不看物品名字，后续同类提灯同样适用。
- 你自己从背包里把提灯拿到手上时，挂腰状态自动解除，交回原版逻辑。

## 前置条件

- 《The Long Dark》**2.55**（本 mod 针对 2.55 编译）
- [MelonLoader](https://melonwiki.xyz/) **0.7.3** 或更高（实测环境 0.7.3）
- **ModSettings**（必需，设置页依赖它）

## 安装

1. 确认游戏目录下已有 `MelonLoader/` 文件夹（没有就先装 MelonLoader 并启动一次游戏）
2. 把 `LanternBelt.dll` 复制到 `TheLongDark/Mods/`
3. 重启游戏

## 使用

1. 打开背包，选中背包里的一盏提灯
2. 在右侧物品面板点「装备」——提灯挂到腰上并亮起
3. 按 `L` 开关，按 `H`（或再点一次「装备」）收起

日常也可以全程不开背包：按 `H` 直接把背包里的提灯挂上，再按一次收起。

设置入口：**选项 → Mod Settings → Lantern Belt**。

## 设置

| 项 | 说明 | 默认 |
|---|---|---|
| 挂起 / 收起提灯 | 一键挂腰或收起，不用开背包。点一下输入框再按想要的键即可改绑 | `H` |
| 开关提灯（仅挂腰时） | 只在提灯挂腰时生效，其余时候按了没有反应 | `L` |
| 允许在装备栏中切换 | 关掉后「装备」恢复原版（拿到手上），挂腰只能靠快捷键 | 开 |
| 装备栏保留原版「装备」 | 开着就完全不动原版装备动作，两项同时开时以本项为准 | 关 |
| 挂上去就点亮 | 关掉则挂上时保持熄灭，需要按开关灯键自己点 | 开 |
| 收起时熄灯 | 关掉则收进背包后灯继续烧油 | 开 |
| 读档后自动恢复 | 读档 / 换场景后自动把点着的提灯重新挂回腰上 | 开 |
| 显示屏幕提示 | 挂上 / 收起 / 没油时在屏幕中间提示一行 | 开 |
| 挂点基准 | 「玩家身体」跟着身体走；「相机」跟视角走，晃动更明显 | 玩家身体 |
| 左右偏移（米） | 负值在左胯，正值在右胯 | -0.20 |
| 上下偏移（米） | 相对脚底的高度 | 0.90 |
| 前后偏移（米） | 正值朝前 | 0.10 |
| 整体缩放 | 挂点选「相机」时通常要降到 0.5 左右 | 1.0 |
| 每帧对齐挂点 | 关掉后灯会留在原地，只在排查问题时关 | 开 |
| 提示语言 | 只影响屏幕提示文字 | 自动 |
| 输出详细日志 | 把挂点、灯光状态写进 `MelonLoader/Latest.log` | 关 |

## 调整挂点位置

默认位置是玩家左胯。如果灯飘在半空、穿进身体或看不见，只调三项偏移即可，全部拖动即时生效，不用重开游戏：

- **灯太低 / 太高**：改「上下偏移」，0.9 大约是腰的高度
- **灯在身体里面**：减小「前后偏移」的负向，或把「左右偏移」往 0 收
- **灯看不见**：先确认不是被衣服挡住，再把「挂点基准」切成「相机」并把缩放压到 0.5 左右

## 卸载

删掉 `TheLongDark/Mods/LanternBelt.dll` 即可。

存档里不会留下本 mod 的字段。已挂腰的提灯在卸载后会变回「背包里一盏点着的灯」，按原版规则它会继续烧油——记得先按 `H` 收起。

## 兼容性

- 只在提灯挂腰的那段时间里接管提灯的位置与开关状态，其余时候对游戏没有任何改动。
- 不修改物品定义、燃油消耗速率、光照强度，也不改装备栏以外的任何界面。
- 与其它装备类 mod 无已知冲突（未做系统性组合测试）；真正会互相影响的是也去接管提灯开关的 mod。

## 常见问题

**点了「装备」没反应？**  
先看设置里「装备栏保留原版『装备』」是不是被打开了；打开时「装备」是原版动作，挂腰要用 `H`。

**`L` 按了没反应？**  
`L` 只在挂腰状态生效。看屏幕提示或按一次 `H` 确认当前是挂上还是收起；也可能是被别的 mod 占用了同一个键，改绑即可。

**灯挂上了但看不见？**  
默认挂在左胯、位置贴近身体，第一人称低头才明显。按上面「调整挂点位置」三项偏移微调。
